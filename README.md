# Project 2 — Patient Dashboard (React + Bootstrap)

## Requirements
- Node.js 18+ and npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Included
- Responsive patient dashboard layout
- Summary cards for blood group and requests
- Searchable request history
- New blood request form (adds a demo row to local React state)
- Navigation tabs and responsive Bootstrap table

Note: All data is sample/demo data stored only in browser memory. No backend, authentication, donor matching, or database is connected.
